About this sticker

This sticker shows the current month and the latest balance.

Opening balance: enter it the first time you use the app, then confirm. After that it is fixed.

Expense: type the amount by hand, confirm, and the balance goes down.

Income: add it by hand each month and confirm. The amount box starts at CA$100.

The balance can go below zero.

Records are kept for 3 months.

Copy ledger copies the books as text, so you can paste them into Google Keep by hand.

Long-press ? to adjust the balance (for corrections).

Everything stays in this phone's browser storage.
